# مدير المولدات | Generator Manager

تطبيق أندرويد عربي لإدارة المولدات الأهلية في العراق: المشتركين، تسعيرة الأمبير، القبض والوصولات، المصروفات والتقارير.

> المواصفات الكاملة: [docs/PRD-001.md](docs/PRD-001.md) — المرجع البصري: [docs/design-reference.png](docs/design-reference.png)

## حالة النسخة 0.1.0 (تجريبية — محلية فقط)

**يعمل:**
- إضافة/تعديل/أرشفة المشتركين (رقم جوزة فريد داخل البورد)
- بحث بالاسم والجوزة والهاتف + فلتر مسدد/متأخر
- تسعيرة الأمبير الشهرية مع معاينة، وإصدار فواتير دون ازدواج (الفواتير الصادرة لا تتغير)
- قبض كامل/جزئي/مقدم بوصل مرقّم، الرصيد مشتق من الدفتر
- طباعة الوصل عبر نظام الطباعة في أندرويد (PDF/طابعة) ومشاركة واتساب
- المصروفات حسب النوع، صافي الربح، تقارير شهرية وحسب البورد
- واجهة عربية RTL بألوان الهوية (بترولي #073B42، ذهبي #F4BD45)

**غير موجود بعد:** Google Sign-In، Firebase والمزامنة، بوابة المشترك، الصلاحيات وتعدد الموظفين، لوحة الأدمن، طابعات POS عبر SDK، استيراد Excel.

## البناء

- تلقائياً: كل push على `main` يبني APK عبر GitHub Actions ويضعه في **Releases**.
- محلياً: `gradlew assembleDebug` (يحتاج JDK 17 و Android SDK).
